The web UI has three columns, from the left.

| Column | What it shows |
|---|---|
| Side | Notebooks or tags; switch them at the top, or with `T` |
| List | The notes of the notebook or tag, or the search results |
| Preview | The note chosen; you edit it here too |

Press `a` to open the assistant on the right ([Using AI](ai.md)).

## Widths of the columns

Drag the border between two columns to change their widths. Double-click it to go back to the default.

## Keys

Outside the input fields, single keys work.

| Key | Action |
|---|---|
| `/` | Go to the search field |
| `j` / `k` | Next / previous note |
| `c` | New note |
| `e` | Edit |
| `s` | Change the order |
| `T` | Switch between notebooks and tags |
| `a` | Assistant |
| `y` / `Y` | Copy the note / copy a link to it |
| `M` | Marks |
| `f` | Find in the note |

## The gear at the bottom left

The settings and upkeep are in the gear menu under the side column ([Settings](settings.md)). The dot at the top right tells whether the page is connected to the server.
