本文は Markdown で書きます。改行 1 つでも、そのまま改行になります。

## 見出し

`#` の数が見出しの深さです。見出しにマウスを乗せると、横にコピーの印が出ます。押すと、その節を Markdown でコピーできます。

## リストとチェック

- 箇条書きは `-` で
  - Tab で字下げ
1. 番号は `1.` で
- [x] 済んだこと
- [ ] まだのこと

## 表

| 書き方 | 見え方 |
|---|---|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `~~取り消し~~` | ~~取り消し~~ |
| `` `コード` `` | `コード` |

## 引用とコード

> 引用は `>` で始めます。

```go
func main() {
	fmt.Println("コードは言語ごとに色が付きます")
}
```

プレビューでは、コードブロックの上の帯（言語と行数）を押すと、そのブロックを畳めます。もう一度押すと開きます。畳んだブロックの中の一致へ移ると、自動で開きます。

## リンク

`[文字](https://example.com)` で外へのリンクです。ほかのノートへのリンクは、題名の後ろの鎖の印（か `Y`）でコピーして貼れます。例: [ようこそ ebira へ](welcome.md)

## ノートのコピー

`y` で、題名を見出しにしたノート全体を Markdown でコピーします。AI にノートを渡すときに便利です。
