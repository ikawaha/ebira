ターミナルで `ebira` を実行すると、Web UI と同じノートを扱う画面（TUI）が開きます。サーバーが動いていなければ、裏で起動します。

画面の下の行に、そのとき使えるキーが出ます。主なキー:

| キー | 働き |
|---|---|
| `j` / `k` | 移る |
| `/` | 検索 |
| Enter | 開く |
| `n` | 新しいノート |
| `e` / `E` | 編集 / `$EDITOR` で編集 |
| `v` | プレビューと Markdown の原文を切り替える |
| `z` | ドキュメントの欄を拡大 |
| `f` | ノートの中を探す |
| `T` | ノートブックとタグを切り替える |
| `x` | アーカイブへ移す・戻す（ノートの一覧ではノート、ノートブックの列ではノートブック） |
| `?` | アシスタントに質問 |
| `q` | 終わる |

## ノートブックの列の特別な行

- Inbox は一番上、Trash は一番下です。その間の「📦 アーカイブ」は、アーカイブに何かあるときだけ出て、下に `↳` でアーカイブのノートのあるノートブックが並びます。
- Trash の下には、捨てたノートブックが `↳` で並びます。Trash の行で `d` を押すと、ゴミ箱を空にします（確かめます）。
- ゴミ箱のノートは編集できず、`u` で元に戻す、`m` でほかのノートブックへ移す、`d` で完全に削除、ができます。捨てたノートブックの行でも `u` と `d` が使えます。
- 検索の結果にアーカイブのノートもあれば、一覧の枠の題名に「アーカイブにも N 件」と出ます。アーカイブの行を選んで同じ検索をすると、アーカイブの中を探します。

原文のモード（`v`）では、ドキュメントの欄がそのまま編集の欄になり、ほかの欄へ移ると保存されます。
