---
title: パスキー
tags: [guide, safety]
---
既定では、このコンピューターから Web UI を開けば、だれでもノートを見られます。パスキーで守るには、次のようにします。

1. `ebira auth passkey` で、パスキーを登録するページを開く
2. 設定ファイルに `auth: passkey` を書き、サーバーを起動し直す

そのあとは、Web UI を開くとパスキーでログインを求めます。TUI とコマンドは、Web UI で承認してつなぎます。

- 非公開を外す・履歴を見る・ゴミ箱を空にするなどの大事な操作では、パスキーをもう一度求めます。
- パスキーは歯車のメニューの「パスキーの管理…」で足し・消せます。
- パスキーを無くしたら、`ebira auth reset` で消して登録し直します。
- MCP は AI のための入り口なので、パスキーは求めません（private のノートブックは見えません）。
