`/` で検索欄へ移り、打つとすぐに探します。検索欄の右端の「?」で、書き方の説明が出ます。

| 書き方 | 見つかるノート |
|---|---|
| `ノート 検索` | 両方の語を含む |
| `"ノートの検索"` | その並びのまま含む（フレーズ） |
| `tag:guide` | そのタグを持つ |
| `mark:red` | そのマークを持つ |
| `-下書き` | その語を含まない（`-tag:`・`-mark:` も） |
| `in:archive` | アーカイブにある（ほかの書き方では、アーカイブのノートは探さない） |
| `pizza OR pasta` | どちらかを含む（大文字の `OR`） |

組み合わせられます: `tag:guide 検索 -mark:red`

検索はゴミ箱とアーカイブのノートを外します。左の列で Trash やアーカイブを選んで検索すると、その中を探します（[ノートとノートブック](notes.md)）。

## 絞り込み

検索は、見つかったノートを関連度の順に並べます。検索欄の右のじょうごのボタン（検索の間は斜線が入っています）を押すと「絞り込み」になり、同じ書き方で、今の一覧を並びのまま絞ります（プレースホルダーが「絞り込み」になります）。

- 手で決めた並び、区切り線、サブノートブックのセルはそのままで、合わないノートだけが隠れます。開いたセルには「出ている数 / 全部の数」が出ます。
- たとえば `-tag:renovate` で、そのタグのノートを外し、残りを並び順のまま見られます。
- 絞ったまま、ドラッグや `J` / `K` で並べ替えられます（見えているノートの間で動きます）。
- どの一覧でも使え、このブラウザが覚えます。もう一度押すと検索に戻ります。

## 一致の印

結果のノートのプレビューでは、一致したところに印が付きます。`n` / `N` で次・前の一致へ移ります。

## 検索方式

検索方式は、ノートのディレクトリの `_ebira.yaml` の `search` で決まります。検索欄のプレースホルダーに今の方式が出ます。

- `ja`: 日本語を単語に分けて探します。活用の違う形も見つかります。
- `en`: 英語の単語と語幹で探します（plan で planning も）。
- `bigram` / `trigram`: 2 文字・3 文字の並びで探します。語の一部でも見つかります。
