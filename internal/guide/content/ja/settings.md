## 歯車のメニュー

- 言語・テーマ（自動・ライト・ダーク）
- 本文の文字の大きさ（− と ＋）
- スタイル…: プレビューの見た目を選ぶ（帯・文書・コンパクト・下線）
- サーバーの設定…: 言語・認証・検索方式など、下の 2 つのファイルの項目を変える
- Markdown を取り込む（ファイルをページにドロップしても）
- ファイルの点検・サーバーの状態・git と同期
- AI とつなぐ（MCP）…: ebira の URL と Claude Code のコマンドを出す。Claude Code にはボタンで登録できる（[AI と使う](ai.md)）
- ガイドを追加
- 要望・不具合を報告: GitHub の Issue を書くページを開く
- 一番下は ebira のバージョン。押すと詳しい版をコピーします（不具合の報告に）

## 設定ファイル

`~/.config/ebira/config.yaml` に書くと、コマンドの既定になります。

```yaml
notes_dir: ~/notes   # ノートのディレクトリ
addr: localhost:13579
lang: ja             # 画面の言語
theme: auto
git_sync: 10m        # git と自動で同期する間隔
auth: none           # passkey でパスキーを求める
```

歯車のメニューの「サーバーの設定…」からも、項目ごとに変えられます（ファイルのコメントは残ります）。設定はサーバーの起動時に読み込まれるので、「保存して起動し直す」を押すと反映されます。ただし `notes_dir` と `addr` は、サーバーを止めてから起動し直したときに反映されます。

ノートと一緒に同期する設定は、ノートのディレクトリの `_ebira.yaml`（検索方式の `search` など）です。

## プレビューの CSS

設定ファイルの隣に `preview.css` を置くと、プレビューの見た目を自分の CSS で変えられます。
