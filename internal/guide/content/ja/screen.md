Web UI は、左から 3 つの列でできています。

| 列 | 中身 |
|---|---|
| 左の列 | ノートブックかタグの一覧。上の切り替えか `T` で替える。上に Inbox、下にアーカイブとゴミ箱（Trash）（[ノートとノートブック](notes.md)） |
| 一覧 | 選んだノートブックやタグのノート。検索するとその結果 |
| プレビュー | 選んだノート。編集もここで行う |

`a` を押すと、右にアシスタントの欄が開きます（[AI と使う](ai.md)）。

## 列の幅

列の境目をドラッグすると、幅を変えられます。ダブルクリックで元の幅に戻ります。

## キー操作

入力欄の外では、1 文字のキーで操作できます。

| キー | 働き |
|---|---|
| `/` | 検索欄へ |
| `j` / `k` | 次・前のノート |
| `c` | 新しいノート |
| `e` | 編集 |
| `s` | 並べ方を替える |
| `T` | ノートブックとタグを切り替える |
| `a` | アシスタント |
| `y` / `Y` | ノートをコピー / リンクをコピー |
| `M` | マーク |
| `f` | ノートの中を探す |

## 左下の歯車

設定や保守の操作は、左の列の下の歯車のメニューにあります（[設定](settings.md)）。右上の点は、サーバーとつながっているかを表します。
