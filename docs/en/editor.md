tags: [guide, writing]

| Key | Action |
|---|---|
| ⌘S / Ctrl+S | Save |
| Esc | Stop editing |
| Tab / Shift+Tab | Indent / outdent |
| Enter in a list | Continue the list |
| ⌘Z / ⌘⇧Z | Undo / redo |
| Ctrl+K / Ctrl+Y (macOS) | Cut the rest of the line / paste it |

## Emoji

Type `:` and two or more letters in the body, such as `:smi`, for emoji. Enter or Tab puts in the emoji itself.

## Undo after saving

When you edit a note again after saving it, the undo history from before is still there. Undo and save to go back to what it was ([History](history.md) works too).

## Enter in the title

Enter in the title field moves to the body; it does not save.
