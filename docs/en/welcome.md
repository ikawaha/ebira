## Try anything

The notes of the guide are notes like any other: change them, or delete them. When you no longer need them, move the notebook to the trash.

Add the guide again at any time with "Add the guide" in the gear menu. It comes as a new notebook each time, and the notes you have stay as they are.

## Notes are plain files

A note is a YAML file in the notes directory (`<notebook>/<ID>.yaml`). You can read it without ebira, and sync it with git or Dropbox as it is. The search index is a copy made from the files, so the files are always the source of truth.
