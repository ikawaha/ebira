title: History
tags: [guide, safety]
---
Each time the title, tags or body of a note change, the earlier version is kept. The clock button at the top right of the preview lists the versions.

- Choose a version to see how it differs from the note.
- "Restore this version" brings its content back. What the note was before is kept as a version too.

## How much is kept

- Up to 50 versions of a note. Versions older than 30 days go, except the newest 5.
- Changes made in another editor or with git become versions when ebira notices them.
- Versions are kept only on this computer, and not synced.

## Earlier files

When an image or another file of a note is replaced by a file of the same name, or deleted (by AI too), the earlier file is kept. "Earlier files" at the bottom of the history dialog lists them, and "Put back" brings one back.

- Putting a file back keeps the file of that name now in its place, so that it can be undone too.
- Up to 20 files of a note. Those older than 30 days go, except the newest 5.
- Like the versions, they are kept only on this computer.

## The trash

Deleted notes stay in the Trash. "Empty trash…" in the menu of the Trash deletes them all for good ([Notes and notebooks](notes.md)). The history of a note deleted for good goes with it.
