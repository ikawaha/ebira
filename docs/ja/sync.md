ノートはただのファイルなので、どの方法でも同期できます。

## Dropbox・iCloud Drive など

ノートのディレクトリを同期のフォルダに置くだけです。2 台で同じノートを同時に変えて「衝突したコピー」ができたら、ebira はそれを `(conflict copy)` の付いたノートにします。どちらも失われません。

## git

ノートのディレクトリを git のリポジトリにすると、ebira が同期します。

- 歯車のメニューの「git と同期」か、`ebira sync` で、コミット・取得・マージ・push をします。
- 設定ファイルの `git_sync: 10m` で、自動で同期します。
- 両方で変えたノートは、相手の版を `(conflict …)` の付いた新しいノートにします。

同期のフォルダの中で git を使うと壊れることがあるので、どちらか 1 つにしてください。
