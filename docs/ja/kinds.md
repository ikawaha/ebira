---
title: ノートブックの種別と AI
tags: [guide, safety, ai]
---
ノートブックごとに、AI（MCP のクライアントやアシスタント）に何を許すかを決められます。種別は、ノートブックの「…」のメニューで替えます。

| 種別 | AI ができること |
|---|---|
| 既定 | 読むだけ |
| collab（共同） | 読む・書く・消す |
| drop（受け皿） | 新しいノートを置くだけ（中は見えない） |
| private（非公開） | 何もできない（ノートブックがあることも見えない） |

Inbox は最初 drop です。このガイドは既定なので、AI に ebira の使い方を聞くと、このガイドを読んで答えられます。

- AI が作ったノートには千鳥の印が付きます（TUI では ✦）。
- アーカイブ: AI の検索も、ふだんはアーカイブを外します。検索の結果でアーカイブにも見つかったことが分かるので、頼まれたときや、ほかのノートで答えられないときはアーカイブも探します（アシスタントは、そのノートがアーカイブにあると伝えます）。collab のノートとノートブックは、AI もアーカイブへ移せます。アーカイブへ移しても種別は変わらないので、private のノートは AI から見えないままです。
- ゴミ箱: AI からは見えません。AI が消したノートもゴミ箱へ移るので、元に戻せます。
- AI は collab のノートに、画像や PDF などのファイルを足せます（1 つ 5MB まで）。シェルのある AI（Claude Code など）は、ebira が渡す使い捨ての URL へ、ファイルを `curl` でそのまま送ります。シェルの無い AI は base64 の文字で送るので、大きなファイルには向きません。
- private を外すときは確かめます。
- 制限は ebira の API を通る AI にだけ効きます。ノートのファイルを直接読める AI は防げません。Claude Code からノートを切り離す設定は「[AI と使う](ai.md)」にあります。
