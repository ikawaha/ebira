## 歯車のメニュー

- 設定…: 下の「設定」のダイアログを開く
- Markdown を取り込む（ファイルをページにドロップしても）
- アーカイブの候補…: しばらく更新していないノートを並べ、選んでアーカイブへ移す（[ノートとノートブック](notes.md)）
- ファイルの点検・git と同期・サーバーの状態
- AI とつなぐ（MCP）…: ebira の URL と Claude Code のコマンドを出す。Claude Code にはボタンで登録できる（[AI と使う](ai.md)）
- ガイドを追加
- 要望・不具合を報告: GitHub の Issue を書くページを開く
- パスキーの管理・ログアウト（パスキーでログインしているとき）
- 一番下は ebira のバージョン。押すと詳しい版をコピーします（不具合の報告に）。右端の GitHub のマークで、ebira のリポジトリを開きます

デスクトップアプリでは、アプリのメニューにあるものは歯車のメニューに出しません（[デスクトップアプリ](desktop.md)）。

## 設定のダイアログ

歯車のメニューの「設定…」（デスクトップアプリは ⌘,）で開きます。左の列で、中身ごとに分けた項目を選びます。

- 表示: 言語・テーマ（自動・ライト・ダーク）・本文の文字の大きさ（− と ＋）・プレビューのスタイル（帯・文書・コンパクト・下線）・マークの名前。
- 検索: 検索方式と、ja のときのストップワード・品詞のストップ。
- 同期: git との自動同期の間隔と、ファイルの監視。
- 連携: Zenn（β）の書き出し先のリポジトリ・ブランチ・ユーザー名（[Zenn に書き出す](zenn.md)）。
- アシスタント: 提供元とモデル。
- TUI: TUI のプレビューと検索欄。
- サーバー: ノートのディレクトリとアドレス、認証、設定のファイルの場所。デスクトップアプリでは、アプリがつなぐノートのフォルダとサーバーのアドレスを出し、「変える…」でアプリの設定のウインドウを開きます（[デスクトップアプリ](desktop.md)）。

項目ごとに値は 1 つです。言語・テーマ・同期・連携・アシスタント・TUI の項目には「ほかの端末とも共有」のチェックがあります。

- チェックを外した値は、この端末の設定ファイル（下の「設定ファイル」）に書き、この端末だけで使います。
- チェックを付けた値は、ノートのディレクトリの `_ebira.yaml` の `defaults` に書き、このノートを同期しているすべての端末の既定にします（下の「複数の端末で設定を共有する」）。この端末の設定ファイルからは、その項目を消します。
- この端末の値とほかの端末と共有している値が両方あるときは、この端末の値を出し、その下に共有している値を添えます。この端末の値を空にすると、共有している値に従います（「共通に従う: …」と出ます）。
- 検索とマークの名前は、いつもすべての端末で共有します。本文の文字の大きさだけは、このブラウザに覚え、すぐに変わります。プレビューのスタイルは、設定ファイルの隣の `preview.css` に書きます。

「保存」で、この端末の設定ファイルと `_ebira.yaml` をまとめて書きます。言語とテーマは、保存するとすぐに変わります（言語を変えるとページを読み直します）。ほかの設定はサーバーの起動時に読み込まれるので、保存したあとサーバーを再起動すると反映されます（下の「サーバーの再起動」）。

## サーバーの再起動

右上の接続の表示（「接続中」）の横の ↻ を押すと、サーバーを同じフラグと環境変数で再起動し、設定ファイルを読み直します。再起動が終わるまでの数秒は、どのクライアントからも使えません。ページは再起動のあとに読み直します。

ふだんは薄く出ています。起動時に読み込まれる設定を保存して、まだ再起動していないあいだは、色が付きます。`go run` で起動したサーバーのように、自分で再起動できないサーバーでは出ません（理由は「サーバーの状態」に出ます）。デスクトップアプリがアプリより古いサーバーに出す ↻ があるときは、そちらだけを出します（[デスクトップアプリ](desktop.md)）。

## 設定ファイル

`~/.config/ebira/config.yaml` に書くと、コマンドの既定になります。

```yaml
notes_dir: ~/notes   # ノートのディレクトリ
addr: localhost:13579
lang: ja             # 画面の言語
theme: auto
git_sync: 10m        # git と自動で同期する間隔
auth: none           # passkey でパスキーを求める
```

キーは `notes_dir`、`addr`、`watch`、`provider`、`model`、`lang`、`theme`（`auto`・`light`・`dark`。`light` なら TUI も明るい配色になります）、`git_sync`、`auth`（`none` か `passkey`）、`tui_preview`（`rendered` か `source`。TUI の `v` で切り替えると書き換えます）、`tui_search`（`search` か `filter`。TUI の検索欄の Tab で切り替えると書き換えます）、`zenn_repo`・`zenn_branch`・`zenn_user`（[Zenn に書き出す](zenn.md)）です。各キーはコマンドのフラグの既定値になり（[コマンド](cli.md)）、知らないキーはエラーになります。API キーは書きません。索引は `~/.cache/ebira` に、サーバーの状態とログは `~/.local/state/ebira` に置きます（XDG の環境変数に従います）。

設定のダイアログからも、項目ごとに変えられます（ファイルのコメントは残ります）。言語とテーマのほかは、サーバーの起動時に読み込まれるので、保存してからサーバーを再起動すると反映されます。ただし `notes_dir` と `addr` は、サーバーを止めてから起動し直したときに反映されます。

ノートと一緒に同期する設定は、ノートのディレクトリの `_ebira.yaml`（検索方式の `search` など）です。

## 複数の端末で設定を共有する

`_ebira.yaml` の `defaults:` に設定ファイルと同じキーを書くと、ノートを同期しているすべての端末の既定になります。端末の設定ファイルに書いた値が優先されるので、端末ごとに変えたい値だけを設定ファイルに書きます。

```yaml
search: ja
defaults:
  lang: ja
  theme: auto
  git_sync: 10m
  model: claude-sonnet-5-5
```

- 値の順は「コマンドのフラグ ＞ 端末の設定ファイル ＞ `_ebira.yaml` の `defaults` ＞ 既定値」です。
- 端末の設定ファイルには、ノートのディレクトリ（`notes_dir`）だけを書けば足ります。
- `notes_dir`・`auth`（ログインの方法）と、localhost 以外の `addr` は、端末ごとの値です。`defaults` に書いても、警告を出して使いません（ほかの端末やノートを共有する人から、パスキーを外されたり、サーバーを外へ開かれたりしないように）。
- 初めてノートを作るときの言語・同期の間隔・アドレスは、`defaults` に書かれます。ほかの端末で既にあるノートを使うときは、`defaults` にある値は聞かれず、`defaults` に無いものへの答えは、その端末の設定ファイルに書かれます。
- `defaults` は、アシスタントの提供元とモデル（その端末の API キーで使われます）や、git との自動の同期も決められます。ノートをほかの人と共有しているときは、`_ebira.yaml` の変更に気をつけてください。
- 前の版の ebira は `defaults` を知らないので、「field defaults not found」と出して起動しません。すべての端末の ebira を上げてください。

## プレビューの CSS

設定ファイルの隣に `preview.css` を置くと、プレビューの見た目を自分の CSS で変えられます。

CSS はノートの本文の中だけに効きます。`h1 { … }` と書いても、ページのほかの部分は変わりません。ページを開くたびに読みます。Web UI の色（`var(--accent)`、`var(--fg)`、`var(--fg-muted)` など）を使えば、ライトとダークのテーマに合わせて変わります:

```css
h1 { border-bottom: 2px solid var(--accent); color: var(--accent); }
h2 { background: var(--accent); color: #fff; border-radius: 4px; padding: 2px 8px; }
hr { border: none; border-top: 2px dotted var(--fg-muted); }
strong { color: #c0392b; }
:root[data-theme="dark"] & strong { color: #f7dc6f; }  /* メニューでダークを選んだとき */
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) & strong { color: #f7dc6f; } }  /* システムがダークのとき */
```

CSS でノートの中身を外へ送れないように、ブラウザに何かを読みに行かせる書き方は取り除きます: `@import` と、`data:` の URL 以外の `url()` などです。端末に入っているフォントは使えますが、Web フォントは使えません。
