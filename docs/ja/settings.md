## 歯車のメニュー

- 設定…: 下の「設定」のダイアログを開く
- Markdown を取り込む（ファイルをページにドロップしても）
- アーカイブの候補…: しばらく更新していないノートを並べ、選んでアーカイブへ移す（[ノートとノートブック](notes.md)）
- ファイルの点検・git と同期・サーバーの状態（「起動し直す」で、サーバーを同じ設定と環境変数で起動し直す）
- AI とつなぐ（MCP）…: ebira の URL と Claude Code のコマンドを出す。Claude Code にはボタンで登録できる（[AI と使う](ai.md)）
- ガイドを追加
- 要望・不具合を報告: GitHub の Issue を書くページを開く
- パスキーの管理・ログアウト（パスキーでログインしているとき）
- 一番下は ebira のバージョン。押すと詳しい版をコピーします（不具合の報告に）

デスクトップアプリでは、アプリのメニューにあるものは歯車のメニューに出しません（[デスクトップアプリ](desktop.md)）。

## 設定のダイアログ

歯車のメニューの「設定…」（デスクトップアプリは ⌘,）で開きます。タブに分かれています。

- アプリ（デスクトップアプリだけ）: アプリがつなぐノートのフォルダとサーバーのアドレス。「変える…」でアプリの設定のウインドウを開きます（[デスクトップアプリ](desktop.md)）。
- 表示: 言語・テーマ（自動・ライト・ダーク）・本文の文字の大きさ（− と ＋）。このブラウザに覚え、すぐに変わります。言語とテーマは、サーバーの設定より優先します。
- この端末: 下の設定ファイルの項目（言語・テーマ・認証・git の自動同期など）と、プレビューのスタイル（帯・文書・コンパクト・下線）。最初の選択肢のまま・空のままの項目は、ノートと共有する既定に従います（「共通に従う: …」と出ます）。
- ノートと同期: 検索方式とマークの名前、各端末の既定（`_ebira.yaml`）。

「この端末」と「ノートと同期」は、「保存」でまとめて書きます。

## 設定ファイル

`~/.config/ebira/config.yaml` に書くと、コマンドの既定になります。

```yaml
notes_dir: ~/notes   # ノートのディレクトリ
addr: localhost:13579
lang: ja             # 画面の言語
theme: auto
git_sync: 10m        # git と自動で同期する間隔
auth: none           # passkey でパスキーを求める
```

設定のダイアログからも、項目ごとに変えられます（ファイルのコメントは残ります）。設定はサーバーの起動時に読み込まれるので、「保存して起動し直す」を押すと反映されます。ただし `notes_dir` と `addr` は、サーバーを止めてから起動し直したときに反映されます。

ノートと一緒に同期する設定は、ノートのディレクトリの `_ebira.yaml`（検索方式の `search` など）です。

## 複数の端末で設定を共有する

`_ebira.yaml` の `defaults:` に設定ファイルと同じキーを書くと、ノートを同期しているすべての端末の既定になります。端末の設定ファイルに書いた値が優先されるので、端末ごとに変えたい値だけを設定ファイルに書きます。

```yaml
search: ja
defaults:
  lang: ja
  theme: auto
  git_sync: 10m
  model: claude-sonnet-5-5
```

- 値の順は「コマンドのフラグ ＞ 端末の設定ファイル ＞ `_ebira.yaml` の `defaults` ＞ 既定値」です。
- 端末の設定ファイルには、ノートのディレクトリ（`notes_dir`）だけを書けば足ります。
- `notes_dir`・`auth`（ログインの方法）と、localhost 以外の `addr` は、端末ごとの値です。`defaults` に書いても、警告を出して使いません（ほかの端末やノートを共有する人から、パスキーを外されたり、サーバーを外へ開かれたりしないように）。
- 初めてノートを作るときの言語・同期の間隔・アドレスは、`defaults` に書かれます。ほかの端末で既にあるノートを使うときは、`defaults` にある値は聞かれず、`defaults` に無いものへの答えは、その端末の設定ファイルに書かれます。
- `defaults` は、アシスタントの提供元とモデル（その端末の API キーで使われます）や、git との自動の同期も決められます。ノートをほかの人と共有しているときは、`_ebira.yaml` の変更に気をつけてください。
- 前の版の ebira は `defaults` を知らないので、「field defaults not found」と出して起動しません。すべての端末の ebira を上げてください。

## プレビューの CSS

設定ファイルの隣に `preview.css` を置くと、プレビューの見た目を自分の CSS で変えられます。
