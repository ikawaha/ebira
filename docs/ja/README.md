# ebira のドキュメント

[English](../en/README.md)

このページたちは、ebira が新しいノートのディレクトリに入れるガイドでもあります（この順に並んだノートのノートブックになります）。

## はじめに

- [ようこそ ebira へ](welcome.md): ebira とは何か、ガイドの読み方
- [入れる・はじめる](install.md): コマンドを入れ、初めてノートを用意する
- [画面の見方](screen.md): Web UI の欄とキー
- [デスクトップアプリ](desktop.md): macOS と Windows のアプリを入れる・新しくする・使う
- [ノートとノートブック](notes.md): ノートブック、サブノートブック、アーカイブ、ゴミ箱、ノートのファイル

## 書く

- [Markdown の書き方](markdown.md): ノートに書ける Markdown
- [数式と図](math.md): KaTeX の数式と Mermaid の図
- [画像とファイル](images.md): 画像やファイルを貼り付け・ドロップでノートに入れる、使われていないものを探す
- [編集欄の便利な操作](editor.md): 編集欄のリスト・字下げ・絵文字・取り消し

## 整理する

- [タグ](tags.md): ノートにタグを付け、タグで一覧する
- [マーク](marks.md): 一覧で目印になる色と記号
- [区切り線と並び順](separators.md): ノートを手で並べ、間に区切り線を置く

## 探す

- [検索の書き方](search.md): 検索の書き方、一覧の絞り込み、検索方式
- [ノートの中を探す](find.md): 開いているノートの中の語を探す

## 守る・戻す

- [履歴](history.md): ノートの前の版と、その版に戻すこと
- [ノートブックの種別と AI](kinds.md): ノートブックごとに AI が読める・書けること

## つなぐ

- [AI と使う](ai.md): MCP で AI クライアントにつなぐ、ツール、アシスタント
- [同期](sync.md): Dropbox・iCloud Drive・git でノートを同期する
- [パスキー](passkey.md): パスキーで Web UI を守る、ebira が守れること

## 見た目と設定

- [設定](settings.md): 設定のダイアログ、設定ファイル、プレビューの CSS
- [ライセンス](licenses.md): ebira と、同梱する部品のライセンス

## ターミナル

- [TUI](tui.md): ターミナルでノートを扱う、そのキー
- [コマンド](cli.md): コマンド、サーバーのフラグ、Markdown の取り込み
