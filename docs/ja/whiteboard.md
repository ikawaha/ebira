title: ホワイトボードで読み解く（β）

AI が書いた説明や差分、計画などを、ホワイトボードに「本筋」として開き、分からない文を選んで付箋で質問しながら読み解けます。付箋にはアシスタントが答えるので、Claude Code などのメインの会話は寄り道で埋まりません。読み終えたら、分かったことや直してほしいことを、開いたセッションに返せます。

> **β です。** 形や操作は、これから変わることがあります。

## 開く

- **Claude Code などの AI から**: ebira を MCP でつないでいれば（[AI と使う](ai.md)）、「この差分を ebira のホワイトボードで開いて」のように頼めます。AI は `start_ai_board` で受け取った URL に本文をそのまま送るか（`curl -T`。本文が会話のトークンになりません）、`open_ai_board` に本文やノートの ID を渡して開き、ホワイトボードの URL を伝えてきます。
- **ノートから**: プレビューの右上の「ホワイトボードで開く」のボタン。開いたときの本文を写すので、あとでノートを直してもホワイトボードは変わりません。
- **一覧**: 左の列の「ホワイトボード」の行（ホワイトボードがあるときだけ出ます。数は開いているものの数）。

本筋は、Markdown ならノートと同じように、差分（diff）とコードと文字だけのものは行番号つきで出します。差分は、足した行と消した行に色が付きます。

## 付箋を付ける

本筋の文を選ぶと、小さな窓が出ます。

- **メモ**: 書いたことを、選んだ文に残します。
- **アシスタントに聞く**: 書いた質問にアシスタントが答えます。答えは裏で作られ、届くと付箋に出ます（待っている間に、ほかの付箋を付けて構いません）。⌘Enter（Ctrl+Enter）でも聞けます。

付箋は本筋の右に、選んだ文の高さにそろえて並びます。選んだ文には印が付き、印を押すと付箋へ、付箋の上の引用を押すと文へ移ります。付箋では続けて質問でき、答えの中の文を選ぶと、その答えに付箋（子付箋）を付けられます。

アシスタントは、選んだ文とその前後、付箋のやりとりを読んで答え、役に立ちそうなら、あなたのノートも探して使います（private のノートブックは見ません）。答えはサーバーの機械の上のアシスタントが作るので、ホワイトボードを使うには、アシスタントの API キーが要ります（無ければメモだけ使えます）。

> **送られる先に気をつけてください。** アシスタントに聞くと、選んだ文の前後（会社のコードなども）が、アシスタントの提供元（Anthropic・Google・OpenAI のどれか）に送られます。

## 理解を終える

右上の「理解を終える」で、開いたセッションに返す文を書きます。

- 付箋の「本筋に返す」に印を付けておくと、「付箋から下書きする」で、アシスタントがその付箋から下書きを作ります。下書きはそのまま返さず、読んで直してください。付箋には PR の本文など外から来た文字が入るので、そこに紛れた指示をセッションへ渡さないためです。
- 「ホワイトボードをノートにする」に印を付けると、返す文・付箋（選んだ文、やりとり、子付箋）・畳んだ本筋を 1 つのノートにして、選んだノートブックに保存します（タグ `whiteboard`）。付けなければ、ノートにはしません。

終えたら、Claude Code に「終わった」と伝えてください。AI は `get_ai_board` で返した文（とノートにしたならそのノートの ID）を読み、本筋を直します。AI が読めるのは返した文だけで、付箋の中身は読めません。

## 置き場所と片付け

ホワイトボードはノートではなく、この機械の状態の場所に置きます。同期されず、検索にも出ません。終えたものは 7 日、開いたまま 30 日触らなかったものは消えます。残したいものは「ノートにする」で残してください。一覧のゴミ箱のボタンで、すぐに消すこともできます。

上限: 本筋は 2MB（AI が本文を直に渡すときは 256KB）、付箋は 200、同時に開いておけるのは 50。
