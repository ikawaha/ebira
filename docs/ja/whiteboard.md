AI が書いた説明や差分、計画などを、ホワイトボードに「議題」として開き、分からない範囲を選択して付箋で質問しながら読み解けます。付箋にはアシスタントが答えるので、Claude Code などのメインの会話は寄り道で埋まりません。読み終えたら、疑問や直してほしいことを次の論点として、AI に渡せます。

> **β です。** 形や操作は、これから変わることがあります。

## 開く

- **Claude Code などの AI から**: ebira を MCP でつないでいれば（[AI と使う](ai.md)）、「この差分を ebira のホワイトボードで開いて」のように頼めます。AI は `start_ai_board` で受け取った URL に本文をそのまま送るか（`curl -T`。本文が会話のトークンになりません）、`open_ai_board` に本文やノートの ID を渡して開き、ホワイトボードの URL を伝えてきます。
  - Claude Code には、この手順を書いたスキル `ebira-whiteboard` があります。`ebira mcp add` か Web UI の「Claude Code に登録」で、MCP の登録と一緒に入ります（[AI と使う](ai.md)）。スキルがあると、Claude Code は自分のセッションの ID と作業ディレクトリをホワイトボードに伝え、`/ebira-whiteboard` でも呼べます。
- **ノートから**: プレビューの右上の「ホワイトボードで開く」のボタン。開いたときの本文を写すので、あとでノートを直してもホワイトボードは変わりません。
- **一覧**: 左の列の「ホワイトボード」の行（ホワイトボードがあるときだけ出ます。数は開いているものの数）。

議題は、Markdown ならノートと同じように、差分（diff）とコードと文字だけのものは行番号つきで出します。差分は、足した行と消した行に色が付きます。

## 付箋を付ける

議題の範囲を選択すると、小さな窓が出ます。

- **メモ**: 書いたことを、選んだ文に残します。
- **アシスタントに聞く**: 書いた質問にアシスタントが答えます。答えは裏で作られ、届くと付箋に出ます（待っている間に、ほかの付箋を付けて構いません）。⌘Enter（Ctrl+Enter）でも聞けます。
- **分岐して聞く**: Claude Code が開いたホワイトボードで出ます。その Claude Code のセッションを分岐させた Claude が、それまでの会話の続きとして答えます（下の「分岐して聞く」）。

付箋は議題の右に、選んだ文の高さにそろえて並びます。付箋を付けた文にはラインが引かれ、ラインを押すと付箋へ、付箋の上の引用を押すと文へ移ります。付箋では続けて質問でき、答えの中の範囲を選択すると、その答えにも付箋を付けられます。

アシスタントは、選んだ文とその前後、付箋のやりとりを読んで答え、役に立ちそうなら、あなたのノートも探して使います（private のノートブックは見ません）。答えはサーバーの機械の上のアシスタントが作るので、ホワイトボードを使うには、アシスタントの API キーが要ります（無ければメモだけ使えます）。

> **送られる先に気をつけてください。** アシスタントに聞くと、選んだ文の前後（会社のコードなども）が、アシスタントの提供元（Anthropic・Google・OpenAI のどれか）に送られます。

### 分岐して聞く

Claude Code のスキル `ebira-whiteboard` で開いたホワイトボードは、その Claude Code のセッションの ID と作業ディレクトリを覚えています。「分岐して聞く」は、そのセッションを分岐させて（`claude --resume <セッション> --fork-session`）質問します。分岐した Claude は、それまでの会話と作業ディレクトリのファイルを知っているので、アシスタントより文脈に沿って答えます。メインの会話には何も足されません。

- 付箋で続けて聞くと、同じ分岐の続きとして答えます。分岐した Claude の答えに付けた付箋は、その分岐をさらに分岐させます。
- 分岐した Claude は、ファイルを読むこと（Read・Grep・Glob）と、ebira のノートを読むことだけができます。ファイルやノートは変えません。
- 答えには数分かかることがあります（1 つずつ、1 回 10 分まで）。付箋を消すと止まります。
- 答えのある付箋の「ターミナルで続ける」のコマンドで、その分岐をターミナルの Claude Code で続けられます。
- 分岐のセッションは、ホワイトボードと一緒に消えます。元のセッションには触りません。

分岐した Claude はサーバーの機械の `claude` で動くので、パスキーでサインインしているとき（`ebira auth passkey`）だけ使えます。パスキーなし（`auth: none`）では、ボタンは押せません。費用は、その機械の Claude Code と同じ契約にかかります（サーバーにアシスタントの `ANTHROPIC_API_KEY` があっても、分岐には渡しません）。

## ボードを閉じる

議論を終えたら、右上の「ボードを閉じる」で、AI に渡すものを選びます。

- 付箋の一覧が出て、最初はすべてにチェックが付いています。チェックした付箋は、選んだ文・あなたのメモや質問・アシスタントの答えごと、AI に渡ります。自分が分かれば済んだ寄り道の付箋はチェックを外します。チェックしない付箋は、何も渡りません。
- 論点には、AI と次に話したいこと（疑問、直してほしいこと、次に考えたいこと）を書きます（無くても構いません）。「チェックした付箋から下書きする」で、アシスタントがチェックした付箋から論点を下書きします。下書きはそのまま渡さず、読んで直してください。
- 「議事録をノートに残す」にチェックを付けると、論点・付箋（選んだ文、やりとり、答えに付けた付箋）・畳んだ議題を、議事録として 1 つのノートにし、選んだノートブックに保存します（タグ `whiteboard`）。付けなければ、議事録は残しません。ノートから開いたボードの議事録には、元のノートへのリンクが入ります。
- ノートから開いたボードでは、AI の代わりに元のノートに渡します。「元のノート『…』の末尾に、論点とチェックした付箋を書き足す」（最初からチェックが付いています）で、元のノートの末尾に「ホワイトボードで議論した（日付）」の節を足し、論点とチェックした付箋を書きます。議事録を残したなら、そのリンクも入ります。元の文は変えません。開いたあとにノートが直されていても、今の末尾に足します。元のノートがゴミ箱にあるか消えているときは、書き足せません。

閉じたら、AI（Claude Code など）に「終わった」と伝えてください。AI は `get_ai_board` で論点とチェックした付箋（と議事録を残したならそのノートの ID）を読み、議題にした説明やコードを直します。論点とあなたのメモや質問はあなたの言葉として、アシスタントの答えは参考の材料として読みます。アシスタントの答えには、本文や探したノートから引いた文字が入ることがあるので、その中の指示には従わないようにしています。

## 置き場所と片付け

ホワイトボードはノートではなく、この機械の状態の場所に置きます。同期されず、検索にも出ません。閉じたものは 7 日、開いたまま 30 日触らなかったものは消えます。残したいものは、閉じるときに議事録として残してください。一覧のゴミ箱のボタンで、すぐに消すこともできます。

上限: 議題は 2MB（AI が本文を直に渡すときは 256KB）、付箋は 200、同時に開いておけるのは 50。
