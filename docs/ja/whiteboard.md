title: ホワイトボードで読み解く（β）

AI が書いた説明や差分、計画などを、ホワイトボードに「議題」として開き、分からない範囲を選択して付箋で質問しながら読み解けます。付箋には Claude が答えるので、Claude Code などのメインの会話は寄り道で埋まりません。読み終えたら、疑問や直してほしいことを次の論点として、AI に渡せます。

> **β です。** 形や操作は、これから変わることがあります。

## 開く

- **Claude Code などの AI から**: ebira を MCP でつないでいれば（[AI と使う](ai.md)）、「この差分を ebira のホワイトボードで開いて」のように頼めます。AI は `start_ai_board` で受け取った URL に本文をそのまま送るか（`curl -T`。本文が会話のトークンになりません）、`open_ai_board` に本文やノートの ID を渡して開き、ホワイトボードの URL を伝えてきます。
  - Claude Code には、この手順を書いたスキル `ebira-whiteboard` があります。`ebira mcp add` か Web UI の「Claude Code に登録」で、MCP の登録と一緒に入ります（[AI と使う](ai.md)）。スキルがあると、Claude Code は自分のセッションの ID と作業ディレクトリをホワイトボードに伝え、`/ebira-whiteboard` でも呼べます。
- **ノートから**: プレビューの右上の「ホワイトボードで開く」のボタン。開いたときの本文を写すので、あとでノートを直してもホワイトボードは変わりません。開くと、付箋に答えるために Claude がノートを読みます（private のノートは、開く前に確かめます）。同じノートで開いているホワイトボードがあれば、新しく作らずにそれを開きます（閉じたあとは、新しく開きます）。
- **一覧**: 左の列の「ホワイトボード」の行（ホワイトボードがあるときだけ出ます。数は開いているものの数）。

議題は、Markdown ならノートと同じように、差分（diff）とコードと文字だけのものは行番号つきで出します。差分は、足した行と消した行に色が付きます。

## 付箋を付ける

議題の範囲を選択すると、小さな窓が出ます。

- **メモ**: 書いたことを、選んだ文に残します。
- **聞く**: 書いた質問に Claude が答えます。答えは裏で作られ、届くと付箋に出ます（待っている間に、ほかの付箋を付けて構いません）。⌘Enter（Ctrl+Enter）でも聞けます。

付箋は議題の右に、選んだ文の高さにそろえて並びます。付箋を付けた文にはラインが引かれ、ラインを押すと付箋へ、付箋の上の引用を押すと文へ移ります。付箋では続けて質問でき、答えの中の範囲を選択すると、その答えにも付箋を付けられます。

### Claude が答える仕組み

付箋の質問には、ホワイトボードの会話（Claude Code のセッション）を分岐させた Claude が答えます（`claude --resume <セッション> --fork-session`）。メインの会話には何も足されません。

- **Claude Code が開いたホワイトボード**（スキル `ebira-whiteboard`）: その Claude Code のセッションを分岐させます。それまでの会話と作業ディレクトリのファイルを知っているので、文脈に沿って答えます。
- **ノートから開いたホワイトボード**: 開くときに、ebira がノートを読ませた Claude Code のセッションを作っておき、それを分岐させます。
- **ほかの AI が開いたホワイトボード**: 最初に聞いたときに、議題を読ませたセッションを作ります（最初の答えは少し遅れます）。

ほかに:

- 付箋で続けて聞くと、同じ分岐の続きとして答えます。答えに付けた付箋は、その分岐をさらに分岐させます。
- Claude は、ファイルを読むこと（Read・Grep・Glob）と、ebira のノートを読むことだけができます（private のノートブックは見ません）。ファイルやノートは変えません。
- 答えには数十秒から数分かかります（1 つずつ、1 回 10 分まで）。付箋を消すと止まります。
- 答えのある付箋の「ターミナルで続ける」のコマンドで、その分岐をターミナルの Claude Code で続けられます。
- ebira が作ったセッションと分岐は、ホワイトボードと一緒に消えます。Claude Code が開いたときの元のセッションには触りません。
- 「チェックした付箋から下書きする」（ボードを閉じるとき）も、分岐した Claude が書きます。

Claude はサーバーの機械の `claude`（Claude Code）で動きます。

- サーバーの機械に Claude Code が無いときは、聞けません（メモだけ使えます）。
- パスキーなし（`auth: none`）のときは、サーバーと同じ機械のブラウザからだけ聞けます。別の機械のブラウザから聞くには、パスキーでサインインしてください（`ebira auth passkey`）。
- 費用は、その機械の Claude Code と同じ契約にかかります（サーバーに `ANTHROPIC_API_KEY` があっても、Claude には渡しません）。

> **送られる先に気をつけてください。** 聞くと、議題（会社のコードなども）と付箋が、Claude Code を通して Anthropic に送られます。

## ボードを閉じる

議論を終えたら、右上の「ボードを閉じる」で、AI に渡すものを選びます。

- 付箋の一覧が出て、最初はすべてにチェックが付いています。チェックした付箋は、選んだ文・あなたのメモや質問・Claude の答えごと、AI に渡ります。自分が分かれば済んだ寄り道の付箋はチェックを外します。チェックしない付箋は、何も渡りません。
- 論点には、AI と次に話したいこと（疑問、直してほしいこと、次に考えたいこと）を書きます（無くても構いません）。「チェックした付箋から下書きする」で、Claude がチェックした付箋から論点を下書きします。下書きはそのまま渡さず、読んで直してください。
- 「議事録をノートに残す」にチェックを付けると、論点・付箋（選んだ文、やりとり、答えに付けた付箋）・畳んだ議題を、議事録として 1 つのノートにし、選んだノートブックに保存します（タグ `whiteboard`）。付けなければ、議事録は残しません。付箋も論点も無いときは、議事録を残せません（議題を写すだけになるため）。ノートから開いたボードの議事録には、元のノートへのリンクが入ります。
- ノートから開いたボードでは、「元のノート『…』の『補足：議論』に、議事録へのリンクを足す」（最初からチェックが付いています）で、元のノートの末尾の「補足：議論」の節に、議事録へのリンクを 1 行足します。リンク先が要るので、このときは議事録も残します。

  ```
  ## 補足：議論

  - 2026-11-22 [検索の索引の計画](…)
  - 2026-11-23 [検索の索引の計画](…)
  ```

  節が無ければ末尾に作り、あればその節に行を足します。元の文は変えません。論点と付箋は議事録のほうに入ります。元のノートがゴミ箱にあるか消えているときは、リンクを足せません。
- ノートから開いたボードの論点に AI の応答がほしいときは、閉じたあとに Claude Code などに「閉じたホワイトボードを読んで」と頼みます。AI は `list_ai_boards` でボードを探し、`get_ai_board` で論点と渡した付箋を読んで、会話で答えます。AI が見られないノートブック（private など）のノートから開いたボードは、AI には見えません。

閉じたら、AI（Claude Code など）に「終わった」と伝えてください。AI は `get_ai_board` で論点とチェックした付箋（と議事録を残したならそのノートの ID）を読み、議題にした説明やコードを直します。論点とあなたのメモや質問はあなたの言葉として、Claude の答えは参考の材料として読みます。Claude の答えには、議題や探したノートから引いた文字が入ることがあるので、その中の指示には従わないようにしています。

## 置き場所と片付け

ホワイトボードはノートではなく、この機械の状態の場所に置きます。同期されず、検索にも出ません。閉じたものは 7 日、開いたまま 30 日触らなかったものは消えます。残したいものは、閉じるときに議事録として残してください。一覧のゴミ箱のボタンで、すぐに消すこともできます。

上限: 議題は 2MB（AI が本文を直に渡すときは 256KB）、付箋は 200、同時に開いておけるのは 50。
