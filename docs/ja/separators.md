## 区切り線

このノートブックの「はじめに」「書く」などの色の付いた線が、区切り線です。ノートの間に置いて、一覧を節に分けます。

- 入れる: ノートの右クリックの「上に区切り線を入れる…」、一覧の下の空いた所の右クリックの「区切り線を入れる…」
- 変える・消す: 区切り線の「…」か右クリック（ダブルクリックでも変えられます）
- 動かす: ドラッグ

見出し・日付・色を持てます。区切り線はノートではないので、検索やタグの対象になりません。手で決める順のときだけ出ます。

## 並び順

一覧の上のメニューか `s` で並べ方を替えます。

| 並べ方 | |
|---|---|
| 並び順 | 手で決める順（ノートブックの既定） |
| 作成日時 | 新しい順 |
| 更新日時 | 新しい順 |
| タイトル | 文字の順 |

手で決める順では、ノートをドラッグするか、`J` / `K` で並べ替えます。並べ方はノートブックごとに覚えます。「すべて」・タグ・検索の結果・ゴミ箱の一覧では並べ替えられません（一覧の中に落とすと、理由が下に出ます）。
