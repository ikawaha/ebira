| 操作 | 働き |
|---|---|
| ⌘S / Ctrl+S | 保存 |
| Esc | 編集をやめる |
| Tab / Shift+Tab | 字下げ・字下げを戻す |
| リストの中で Enter | 次の項目を続ける |
| ⌘Z / ⌘⇧Z | 取り消し・やり直し |
| Ctrl+K / Ctrl+Y（macOS） | 行の残りを切り取り・貼り付け |

## 絵文字

本文で `:` に続けて 2 文字以上（`:smi` など）打つと、絵文字の候補が出ます。Enter か Tab で、絵文字そのものが入ります。

## 取り消しは保存のあとも

保存したあとで編集し直しても、保存の前の取り消しの履歴が残っています。取り消して保存すれば、前の内容に戻せます（[履歴](history.md) も使えます）。

## 題名の欄で Enter

題名の欄で Enter を押すと、本文へ移ります。保存はしません。
